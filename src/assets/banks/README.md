# Logo bank dan e-wallet

Taruh logo resmi di sini (SVG, PNG, atau WebP). Nama berkas harus persis salah satu ini:

bca, mandiri, bni, bri, seabank, bank-jago, krom, dana, ovo, gopay, shopeepay

Contoh: `bca.svg`, `dana.png`. Logo dipakai otomatis di semua avatar rekening; rekening tanpa berkas logo tetap memakai monogram berwarna. Unduh logo dari halaman brand/press kit masing-masing bank. Hasil build otomatis ikut tersimpan untuk mode offline.
